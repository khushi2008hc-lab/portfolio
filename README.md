## ✨ Features

- **🪐 3D WebGL Cosmos & Floating Geometry:** Powered by Three.js with real-time mouse-tracking camera parallax and inertia damping.
- **🖥️ In-Browser SQL Lab:** Interactive query console allowing visitors to query in-memory relational tables (`developer_profile`, `technical_skills`, `portfolio_projects`, `hire_khushi`) with sub-millisecond execution telemetry.
- **🎴 Dynamic 3D Card Tilt:** Smooth mouse perspective transforms with specular glare reflections.
- **🎨 Dynamic Theme Palette:** Instant real-time accent switching (Cyber Cyan, Royal Purple, Plasma Pink, Matrix Emerald).
- **🔊 Web Audio API Synthesizer:** Zero-latency procedural UI click and celebration sound effects.
- **📱 Fully Responsive Bento Grid:** Tailored layouts for widescreen, desktop, tablet, and mobile.
- **🎉 Confetti Feedback:** Interactive contact form with live validation and particle celebration.

## 🛠️ Tech Stack

- **Core:** HTML5, Modern Vanilla JavaScript (ES6+)
- **Styling:** Modern CSS3, Flexbox, CSS Grid, Glassmorphism, CSS Custom Properties
- **3D Graphics:** Three.js (WebGL)
- **Audio:** Web Audio API Procedural Synthesis
- **Deployment:** GitHub Pages & Vercel
